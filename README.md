# Судові засідання: дані

Щоденна копія відкритого набору ДСА України «Список справ призначених до розгляду»
([data.gov.ua](https://data.gov.ua/dataset/3a321301-a06f-487b-9d19-e6b917250aee), ліцензія CC-BY 4.0),
нарізана на невеликі файли для мобільного застосунку.

- Гілка `data`: `meta.json` і `s/<код суду>_<рік>.json`, наприклад `s/464_26.json` для справи 464/3078/26.
- Рядок файлу: `[дата, номер справи, суд, зала, судді, учасники, суть]`.
- Оновлення: щодня о 07:20 і 16:20 за Києвом (`.github/workflows/daily.yml`).

Джерело даних: Державна судова адміністрація України.
