# Судові засідання: дані

Щоденна копія відкритих наборів ДСА України, нарізана на невеликі файли для мобільного застосунку:

- «Список справ призначених до розгляду» ([data.gov.ua](https://data.gov.ua/dataset/3a321301-a06f-487b-9d19-e6b917250aee));
- «Єдиний державний реєстр судових рішень» за поточний і два попередні роки (метадані документів, без текстів).

Ліцензія даних: CC-BY 4.0.

- Гілка `data`: `meta.json` і `s/<код суду>_<рік>.json`, наприклад `s/464_26.json` для справи 464/3078/26.
- Рядок файлу засідань: `[дата, номер справи, суд, зала, судді, учасники, суть]`.
- `d/<код суду>_<рік>_<середнє число % 4>.json`: документи ЄДРСР, рядок `[doc_id, номер справи, форма, дата, суд, суддя, категорія, вид судочинства]`; текст: `https://reyestr.court.gov.ua/Review/<doc_id>`.
- `dicts.json`: довідники судів, форм рішень, категорій.
- `p/<код суду>_<рік>.json`: учасники справ, накопичені з усіх засідань: `{ "номер справи": [учасники, суть, дата засідання] }`.
- Оновлення: щодня о 07:20 і 16:20 за Києвом (`.github/workflows/daily.yml`).

Джерело даних: Державна судова адміністрація України.
